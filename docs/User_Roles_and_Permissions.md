# User Roles and Permissions

## Introduction

The Lab Resource Utilization Platform supports multiple user roles. Each role has specific responsibilities and permissions to ensure secure access and efficient management of laboratory resources.

---

## 1. Researcher / Student

### Responsibilities
- Search available laboratory equipment.
- View equipment details and availability.
- Book equipment for experiments or research.
- View booking history.
- Receive booking notifications.

### Permissions
- View available equipment.
- Create equipment booking requests.
- Cancel their own bookings.
- View personal profile.
- Receive notifications.

---

## 2. Lab Technician

### Responsibilities
- Monitor equipment condition.
- Perform equipment maintenance.
- Update calibration records.
- Record equipment usage.
- Verify equipment availability.

### Permissions
- Update equipment status.
- Create maintenance records.
- Create calibration records.
- View equipment bookings.
- Manage assigned laboratory equipment.

---

## 3. Lab Manager

### Responsibilities
- Manage laboratory inventory.
- Approve or reject booking requests.
- Monitor equipment utilization.
- Generate laboratory reports.
- Schedule maintenance.

### Permissions
- Add, update, and remove equipment.
- Approve bookings.
- View utilization reports.
- Manage laboratory resources.
- View maintenance schedules.

---

## 4. Department Head

### Responsibilities
- Monitor department laboratory resources.
- Approve departmental resource requests.
- Review utilization reports.
- Manage department users.

### Permissions
- View department reports.
- Monitor department equipment.
- Approve department resource requests.
- View departmental analytics.

---

## 5. Institution Administrator

### Responsibilities
- Manage institution-wide resources.
- Monitor all laboratories.
- Manage departments.
- View institutional reports.
- Configure system settings.

### Permissions
- Manage users.
- Manage departments.
- Manage laboratories.
- View institution-wide analytics.
- Generate reports.

---

## 6. System Administrator

### Responsibilities
- Maintain the complete platform.
- Configure security settings.
- Manage user roles.
- Monitor system performance.
- Maintain audit logs.

### Permissions
- Full system access.
- Manage all users.
- Configure role-based access.
- Monitor audit logs.
- Manage application settings.

---

## Role-Based Access Control (RBAC)

The application follows Role-Based Access Control (RBAC). Every user is assigned a specific role, and permissions are granted based on that role. This improves security, prevents unauthorized access, and ensures that users can perform only the actions relevant to their responsibilities.
