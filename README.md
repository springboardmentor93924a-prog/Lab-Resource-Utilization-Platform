# Lab Resource Utilization Platform

## Overview

The Lab Resource Utilization Platform is a web-based application developed to efficiently manage laboratory resources across multiple institutions. It enables administrators, lab managers, technicians, researchers, and students to manage equipment, bookings, maintenance, calibration, and utilization through a centralized system.

## Features

- User Authentication & Role-Based Access Control (RBAC)
- Institution & Department Management
- Equipment Management
- Booking Management
- Resource Sharing
- External Booking
- Maintenance Management
- Calibration Management
- Utilization Tracking
- Notification System
- Reports & Dashboard
